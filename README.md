# Frontend Web Gerenciamento

Frontend de um sistema de gerenciamento desenvolvido para permitir autenticação e cadastro de usuários através de uma interface web simples e funcional.

A aplicação consome uma API simulada utilizando **JSON Server**, realizando requisições HTTP com **Fetch API** para manipulação dos dados.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON Server

## Funcionalidades

- Tela de login
- Cadastro de usuários
- Validação de campos no formulário
- Consumo de API para leitura e envio de dados
- Integração com servidor local via JSON Server
